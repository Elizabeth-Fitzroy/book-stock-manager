# 古本仕入れ総合支援システム (Book Stock Manager - Android)

古本・コミック仕入れ現場（ブックオフ等）および仕入れ前リサーチにおいて、
棚の背表紙撮影やキーワード検索から「店頭にある巻」「自宅在庫（スプレッドシート）の巻」「全巻数」「抜け巻」「相場（メルカリ/Amazon）」を瞬時に判定・可視化する総合支援ツールです。

Sony Xperia 10 II (SO-41A) などの実機スマートフォンに最適化された Android ネイティブアプリ（Kotlin / Jetpack Compose）として実装されています。

---

## 📱 主要機能ハイライト

- **📷 高速棚スキャン & 背表紙AI解析**:
  - Xperia 10 II の標準カメラ連携（FileProvider対応）および写真選択。
  - **Gemini 3.5 Flash-Lite** を標準採用した超高速・高精度な背表紙解析（ハルシネーション抑制プロンプト完備）。
  - 設定ダイアログから `Gemini 3.8 Flash`, `Gemini 4 Hydrogen` へワンタップ切り替え可能。
  - **🔄 利用可能モデル手動更新**: 音声合成（TTS）や画像生成等の非対象モデルを自動除外した最新マルチモーダルモデル一覧の取得・更新に対応。
- **🔍 1タップ Google レンズ連携**:
  - 撮影画像そのものを手渡して Google レンズを起動し、定型照合プロンプトを自動コピー。
- **📊 スプレッドシート（Stock_Summary）完全同期**:
  - **INDEX + MATCH 動的ヘッダー参照**: 列順の変更や列追加があっても壊れない堅牢な自動パース。
  - **コンディション別数量表示**: 通常・帯あり・初版・新装版・ダメージ（ヤケ/折れ/破れ/濡れ/汚）の実数をバッジで明示。
  - **🚨 在庫0冊（要仕入!）ハイライト**: 自宅在庫なし（0冊）のISBNを琥珀色背景とゴールド枠線で強調表示。
- **📚 複雑な巻数・シリーズ構成の自動突合**:
  - 『指輪物語』等の複合枝番巻（`上1`, `上2`, `下1`, `下2`）の完全独立識別。
  - 『トワイライト』等のローマ数字上下巻（`2-上`, `2-下`）の完全独立識別。
  - 『獣の奏者』等の編名（闘蛇/王獣/探求/完結）自動マッピング。
- **🛍️ ダイレクト相場＆利益試算**:
  - 店頭巻＋自宅在庫による完結判定と、メルカリ売切相場・Amazon最安値・見込み純利益の瞬時試算。

## 🧩 モジュール構成

```text
[カメラ撮影 / ギャラリー選択 / ユーザー入力]
          │
          ▼
┌─────────────────────────────────┐
│ Module 2: Vision/Shelf Analyzer │ ── (背表紙AI画像解析: Gemini 3.5 Flash-Lite / 3.8 Flash / 4 Hydrogen)
└─────────────────────────────────┘
          │ 撮影抽出リスト (ScannedSpine[])
          ▼
┌─────────────────────────────────┐
│ Module 3: Set Matcher Engine    │ ◄─── Module 1: Stock Provider (動的ヘッダー在庫リスト)
└─────────────────────────────────┘
          │ 突合判定結果 (MatchedSeriesStatus[])
          ▼
┌─────────────────────────────────┐
│ Module 4: Market Researcher     │ ── (安全なダイレクト相場試算・外部リンク生成)
└─────────────────────────────────┘
          │ 表示用カードリスト (CardDisplayItem[])
          ▼
┌─────────────────────────────────┐
│ UI Layer (Jetpack Compose)      │ ── (AndroidネイティブUI: 棚判定 / 在庫検索 / 設定)
└─────────────────────────────────┘
```
